# P2P Room Booking Canva UI Kit

Use this file as a direct design brief for Canva mobile app screens.

## Brand Direction

- Product name: `P2P Room Booking`
- Visual mood: `secure`, `friendly`, `modern campus utility`, `simple but premium`
- Style: soft cards, rounded corners, warm orange highlights, clean white backgrounds
- Audience: students, staff, or teams booking rooms quickly on mobile

## Color Palette

- Primary: `#F27038`
- Primary dark: `#D85A1A`
- Soft peach: `#FFF3EB`
- Warm card: `#FDE1D0`
- Surface: `#FFFFFF`
- Text dark: `#102A43`
- Text muted: `#5C6B7A`
- Success: `#2E7D32`
- Warning: `#F9A825`
- Error: `#D32F2F`
- Divider: `#E6ECF2`

## Typography

- Heading font: `Poppins Bold`
- Body font: `Poppins Medium`
- Small labels: `Poppins Regular`
- Screen title: `28-32`
- Section title: `20-22`
- Card title: `16-18`
- Body text: `13-15`
- Button text: `15-17`

## Global UI Rules

- Canvas size: `1080 x 2400`
- Safe margin: `48px` left/right
- Corner radius: `28px` for cards, `22px` for inputs, `26px` for buttons
- Shadow: soft orange-gray shadow, low blur
- Icons: rounded outline icons
- Buttons: solid orange primary button, soft peach secondary button
- Inputs: white background, left icon, subtle border, large tap area
- Top bar: clean, status bar visible, no clutter

## Canva Prompt

Use this prompt inside Canva Magic Design or any AI design tool:

`Design a premium mobile app UI kit for a product called P2P Room Booking. Style should be modern, secure, warm, and minimal. Use orange (#F27038), dark navy text (#102A43), soft peach backgrounds (#FFF3EB), white cards, rounded corners, clean status cards, booking list cards, right-side profile drawer, and polished login/signup/create booking/edit booking/conflict resolution screens. Make it look like a real production-ready Android app for room booking and peer-to-peer sync.`
